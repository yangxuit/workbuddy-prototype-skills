# 交互深度要求（必读）

## 1. 深度分档（按【交互深度档位】选择，默认 L3）

**L1 · 结构评审版**（用于快速确认信息架构）

- 完整布局 + 导航路由 + 静态数据渲染；按钮 hover 态；视图切换动画
- 允许部分次级按钮为"规划中"禁用态；无表单校验、无异步模拟
- 交付速度优先，单文档建议 1 次生成完成

**L2 · 标准管理后台版**

- L1 全部 + 筛选器组（Tab + 下拉 + 关键词回车搜索）+ 表格分页 + 行点击抽屉 + 表单校验（红框/首错聚焦）+ Toast 反馈 + 二次确认 + 按钮 loading 态 + 1~2 个 ECharts + 空态设计
- 数据走 API 桩（含拟真延迟），渲染直读 DB

**L3 · 深度演示版（默认）**

- L2 全部 + 以下增强项（按业务适用性取用，鼓励全部实现）：
  - **业务流程闭环**：审批/处置/整改流（多节点步骤条 + 时间线 + 按节点渲染操作区 + 驳回回退 + 状态跨视图联动刷新）
  - **业务计算器**：把行业规则做成可交互计算（如 LEC 评估滑杆实时算分、阈值判定、单位换算、加权指数试算）
  - **实时感模拟**：定时器数据抖动/随机游走 + 模板池推送新记录（`document.hidden` 时跳过）+ 越限检测触发 Toast/蜂鸣
  - **倒计时**：时限类业务做真实倒数（考试 600s 分段变色到点自动交卷、法定 24h 处置倒计时横幅）
  - **AI 过程感**：识别步骤流水线动画（逐个 灰→蓝→绿）+ 打字机输出 + 强制引用溯源块
  - **自驱动作链**：doing 项 3~4s 自动变 done（模拟边缘执行回执），页面"自己往前走"
  - **移动端模拟器**：纯 CSS 手机机身（330px 圆角边框 + 状态栏 + 内滚动 body）演示移动场景（拍照/语音/扫码）
  - **GIS 一张图**：程序化构建 SVG 厂区/园区底图（网格 + 道路 + 分区多边形 + 多图层标记 + 图层开关 + 点击下钻 + 定位脉冲环）
  - **视频墙**：CSS 造监控画面（渐变 + 噪点 + 扫描线 + AI 检测框 + REC 红点 + 离线格）+ 轮巡 + 点击放大
  - **热力图下钻**：div 网格热力 + 点击下钻切换明细 + chip 过滤 + 行点击再开抽屉（三级下钻深度）

## 2. 交互范式规则（不分档，强制遵守）

1. **危险/不可逆操作必须 `confirmModal({danger:true})` 二次确认**，确认按钮红色。
2. **驳回/拒绝类操作必须强制填写意见**，空意见红框拦截。
3. **所有异步动作的按钮 loading 文案化**（"××中…"），完成后恢复并给出结果 Toast；危险结果附加 `beep()` 声光提示。
4. **表单校验三件套**：必填星号 + 错误红框 + `.a-err` 文案；数字范围/正则格式/成对交叉校验（如预警值 < 报警值）按业务补齐。
5. **状态变更必须联动刷新所有受影响区域**（表格 + 统计卡 + 顶栏告警灯 + 关联视图的 `built` 态），不留"改了这边那边还是旧数据"的破绽。
6. **跨页跳转带上下文**：`xx.html#/key` 直达 + 必要时 setTimeout 等挂载 + 定位/高亮目标对象。
7. **Esc 键统一关闭**最上层弹层（Modal > 抽屉 > 导航抽屉依次让位）。
8. **空态设计**：每个列表/详情区给出引导文案（如"点击左侧人员查看画像"），禁止留白破相。

## 3. 演示与叙事策略（生成页面时同步落地）

1. **剧本按钮**：每个关键机制配一个"模拟 XX"按钮（模拟新告警/模拟等级变更/模拟泄漏判定/模拟超时升级），让评审者无需等待就能触发完整链路；触发后多出 UI 同步变化（KPI 卡变色 + 图表追加 + 横幅出现 + Toast + 蜂鸣），一次点击驱动 5~6 处状态同步。
2. **定时推送节奏**：实时感推送间隔 50~55s，后台标签页（`document.hidden`）跳过，避免多页同开时互相干扰。
3. **闭环回流叙事**：跨模块业务动作（催办/阻断/判定）统一向"告警中心"回流一条新告警并刷新顶栏告警灯，形成"任何模块的动作都能在告警中心看到回音"的产品故事。
4. **角色视角**：按文档切换登录人（安全总监/系统管理员），体现权限差异。
5. **能力诚实标注**：远期规划能力一律 `disabled` + "P1/P2 规划中"徽标，宁可少演示不伪造；这反而是专业度的加分项。
6. **口径脚注**：页脚固定"纯静态演示，全部数据为虚构 Mock"声明，避免数据被误当真实。

需要把原型升级为"放映机式引导演示"（宣讲场景）时，使用 demo-tour 技能。
