# UI 设计规范

## 1. 双产品形态（所有风格预设通用）

| 维度 | 管理后台形态 | 大屏驾驶舱形态 |
|---|---|---|
| 外壳 | `admin-shell`：216px 白色侧栏 + 52px 顶栏（面包屑/告警灯/时钟/用户）+ 滚动内容区 | `screen-shell`：100vh 网格（64px 顶栏 + 1fr），`overflow:hidden` 不滚动，滚动下沉到面板内部 |
| 二级导航 | 侧边菜单（NAV_DOCS 注入） | 顶栏居中 Tab |
| 视觉气质 | 锐利、留白、文档流 | 深空底、发光边、HUD 切角、氛围动效 |
| 页面模型 | 纵向滚动叙事 | 满屏一屏决策 |
| 数字字体 | 关键统计用 Bahnschrift | 全局 `--f-digits` Bahnschrift + `--f-mono` 等宽 |

布局原语（两形态通用）：双栏 `1fr + Npx` / `Npx + 1fr`、三栏 `300px 1fr 312px`、KPI 行 `repeat(5~6,1fr)`、卡片网格 `repeat(3~4,1fr)`；`min-height:0` 防 grid 溢出；响应式断点 **1200px**（双栏塌单栏、侧栏收窄为图标态）与 **768px**（全单列、隐藏侧栏）；设计基准 1920×1080。

## 2. 风格预设（四选一，默认 S1）

**S1 · 工业科技蓝（默认）**

- 主色：`#165DFF`，hover `#4080FF`，active `#0E42D2`，浅底 `#E8F3FF`；渐变主轴 `#0E42D2 → #4080FF`
- 浅色形态：底 `#F2F3F5`，面 `#FFF`，边 `#E5E6EB`，文字三级 `#1D2129 / #4E5969 / #86909C`
- 深色形态：底 `#070D1F`（三层径向渐变光晕），面 `#0D1730 / #111D3B`，边 `#1D2C52` + 发光边 `rgba(64,128,255,.45)`，文字 `#E9F0FC / #8CA0C9 / #5B6E96`
- 语义色：成功 `#00B42A`、警告 `#FF7D00`、危险 `#F53F3F`；四色分级：红 `#F53F3F`、橙 `#FF7D00`、黄 `#FFC400`、蓝 `#165DFF`
- 圆角：浅色控件 2px / 卡片 8px；深色 4/8/12px；阴影低饱和 `rgba(29,33,41,.06~.10)`
- 专属语言：panel 四角 HUD 切角、告警灯呼吸、扫描线、等宽数字
- 适用：工业安全、智能制造、能源、安防监控

**S2 · 生态科技绿**

- 主色 `#00B42A`，hover `#23C343`，active `#008A4B`，浅底 `#E8FFEA`；深色底 `#06170E`，面 `#0B2417`，发光边 `rgba(35,195,67,.45)`
- 语义映射：主操作绿、危险保持 `#F53F3F`、警告 `#FF7D00`、信息 `#0FC6C2`
- 气质：环保、双碳、新能源、水务、生态监测；图形语言偏向叶脉/水波曲线装饰
- 适用：环保监测、双碳平台、新能源场站、水务

**S3 · 政务稳重红**

- 主色 `#C9272A`（党旗红系），hover `#D94043`，active `#A61F22`，浅底 `#FDECEC`；深色底 `#1A0A0C`，面 `#2A1013`，发光边 `rgba(217,64,67,.45)`
- 辅助金 `#B88230` 用于荣誉/表彰类元素；语义色保持国家标准红黄绿蓝
- 气质：庄重、徽章感、宋体大标题点缀（标题可用衬线强化政务感）
- 适用：党建、政务大厅、监管报送、国企集团汇报

**S4 · 暗紫数据风**

- 主色 `#722ED1`，hover `#9254DE`，active `#5B1FA8`，浅底 `#F4EBFE`；深色底 `#0E0819`，面 `#170E2B`，边 `#2E2050`，发光边 `rgba(146,84,222,.45)`
- 双辅色：青 `#13C2C2`（数据流）+ 品红 `#EB2F96`（告警点缀）
- 气质：数据中台、AI 平台、算法驾驶舱；装饰语言偏粒子/网格拓扑
- 适用：数据资产、AI 中台、算法平台、数字化底座

> 选定预设后，第 1 节的形态规范与第 3 节的组件规范不变，仅色彩令牌与装饰语言随预设替换。四套预设的语义色（成功/警告/危险）保持一致，确保跨项目的可读性惯例。

## 3. 组件规范（类名体系）

- **按钮**：`.btn` 34px 高 + `.btn-primary/.btn-danger/.btn-ghost/.btn-sm`；loading 态 = 禁用 + 文案改"××中…"（如"接警中…/保存中…/执行中…"），完成后在 `.then()` 内恢复
- **标签**：`.a-tag` + 语义修饰 `.ok/.wait/.red/.orange/.yellow/.blue/.green`（色值/浅底/描边三件套）
- **表格**：`.a-table`，表头 sticky 浅灰底，编号/时间列用等宽 `.mono`；前端分页（每页 10 条 + 上一页/下一页 + 越界 Toast）
- **表单**：`.a-field` + 必填星号 `.req` + `.a-input/.a-select/.a-textarea` + 错误态 `.error` 红框 + `.a-err` 文案；focus 蓝环；提交校验失败聚焦首个错项
- **抽屉**：`.a-drawer` 440px 右滑（`cubic-bezier` 过渡），遮罩 + Esc 关闭；键值展示用 `76px` 标签列网格
- **步骤条**：`.a-steps`（done/cur 状态色）+ CSS 垂直时间线（轴线 + 末节点高亮），审批流两者叠加使用
- **统计卡**：`.a-stat-row` 五列 KPI + `.a-stat`（大数字 Bahnschrift + 小标签）
- **开关/页签**：纯 CSS `.a-switch` 滑块；`.a-tabs` 胶囊分段控件
- **Toast**：右上角 `#toast-root`，四态（success/warning/info/danger）图标 + 标题 + 描述，3600ms 自动退场

## 4. 动效规范

- **入场**：视图切换时卡片阶梯入场（`arcoRise/cardIn`，每项延迟 0.05~0.06s 递增），重进视图需强制重启动画
- **常驻氛围（深色形态）**：告警灯 `lampBlink` 红光呼吸、告警点 `coreBlink` 闪烁、视频扫描线 `vscan`、定位环 `spinRing` 旋转、滚动条 `marquee` 无缝跑马灯（内容双份 + translateX -50%）
- **状态呼吸分级**：警告级 2s 周期、危险级 1.1s 周期，用频率区分紧迫度
- **过程感动画**：AI 输出打字机（每 12~28ms 输出 2~4 字符 + 光标闪烁）、步骤流水线（每步 550~650ms 逐个 灰→蓝→绿）、进度条宽度 1s `cubic-bezier` 过渡
- **克制原则**：浅色管理形态只保留入场与 hover 过渡；氛围动效仅用于深色大屏与警示元素
