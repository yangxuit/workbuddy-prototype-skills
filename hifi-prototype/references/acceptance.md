# 质量验收清单（每次交付前自查，逐项打勾）

## 运行健康

- [ ] 双击直接打开可运行，控制台零报错、零警告
- [ ] 全程无网络请求（断网可用），仅引用本地 `_shared` 资源
- [ ] hash 路由刷新/直链/前进后退均正确恢复视图
- [ ] 1920 / 1200 / 768 三档宽度布局不破相
- [ ] 所有定时器在视图离开后已清理，长时间挂机无内存泄漏迹象

## 交互完整

- [ ] 逐个点击所有可见按钮/链接/开关，无死操作（含禁用态有标注原因）
- [ ] 每个表单校验路径实测（空值/越界/格式错/交叉校验）
- [ ] 每个危险操作有二次确认；每个驳回强制意见
- [ ] 抽屉/Modal 开关、Esc、遮罩点击三种关闭方式均有效
- [ ] 状态变更后所有关联区域（表格/统计/灯/跨视图）已同步

## 数据可信

- [ ] 汇总数与明细条目对账一致；跨页同一对象口径一致
- [ ] 无占位文字（lorem/待补充/XXX）；电话已脱敏
- [ ] 页面内无散落硬编码业务数据（全部来自 DB）

## 视觉规范

- [ ] 色彩/圆角/字号符合所选风格预设令牌
- [ ] 深色形态氛围动效、浅色形态克制原则落实
- [ ] 图表配色统一（预设主色渐变），轴线/tooltip 深浅匹配
