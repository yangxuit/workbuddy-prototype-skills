# 输入槽位全表 · 默认值与填写示例

hifi-prototype 技能的输入参数字典。第 2 步收集槽位时以本表为准。

## 槽位全表

| 槽位 | 必填 | 默认值 / 可选项 | 说明 |
|---|---|---|---|
| 运行模式 | 是 | A / B | A=全新项目从零建五层架构；B=延续项目复用现有 `_shared` 层 |
| 项目名称 | 是 | — | 例：XX园区智慧安全管理平台 |
| 模块清单 | 是 | — | 一级模块 × 二级页面清单，建议格式：编号+名称+key |
| 虚构主体设定 | 否 | 从项目名派生 | 数据"世界观"主体，例：临江装备制造有限公司（机加/焊接/总装/动力四车间） |
| 行业与业务域 | 否 | 从项目名推断 | 例：装备制造 · 车间设备与能效管控 |
| 依据文档 | 否 | 无 | 例：《前端功能导航 V1.3》《全量功能清单 V1.2》；有则附路径或内容 |
| 页面形态 | 否 | 管理后台 | 大屏驾驶舱 / 管理后台 / 混合（指明哪些模块用哪种形态） |
| 视觉风格预设 | 否 | S1 | S1/S2/S3/S4，详见 references/ui-spec.md |
| 交互深度档位 | 否 | L3 | L1/L2/L3，详见 references/interaction.md |
| 数据规模 | 否 | 每数据域核心条目 5~15 条 + 汇总统计 | 详见 references/data-spec.md |
| 贯穿性剧本 | 否 | 无 | 例：G-07 探测器断流 24h 倒计时贯穿五个模块 |
| 特殊机制 | 否 | 无 | 业务上必须演示的独有机制，例：配电房智能门禁"双人授权才可进入" |
| 交付批次 | 否 | 门户先行，按模块每批 1~2 个交付 | 详见 references/delivery.md |

## 填写示例（平台级项目，全虚构演示项目，参考后按实际项目替换）

```
【运行模式】A
【项目名称】临江装备制造智能工厂管理平台
【虚构主体设定】临江装备制造有限公司（机加/焊接/总装/动力四车间，厂区 SVG viewBox 0 0 1520 860）
【行业与业务域】装备制造 · 设备与能效全域管控（设备健康 + AI 赋能）
【依据文档】《前端功能导航 V1.3》：11 个一级功能 61 个二级页面（示例结构，按实际替换）
【模块清单】01 安全态势(map/risk/score/realtime) ｜ 02 报警中心(pool/grade/handle/watch/link/review) ｜
  03 风险管控(identify/control/special) ｜ 04 隐患治理(task/report/loop/patrol/ledger/trace) ｜
  05 作业管控(eticket/supervise/verify/unmanned) ｜ 06 人员管控(locate/fence/behavior/profile/wearable/gate/contractor/visitor) ｜
  07 设备设施(ledger/monitor/predict/power/sensor/algo) ｜ 08 应急指挥(emap/plan/drill/resource) ｜
  09 合规管控(law/rule/cert/train/kb/duty/accident/standard/health) ｜ 10 智能分析(aireport/aichat/model/asset) ｜
  11 系统管理(org/msg/selfcheck/api/audit/twincfg/edge)
【页面形态】01 全大屏；02 的 2.4 值守台与 08 的 8.1 应急一张图为深色视图；其余管理后台
【视觉风格预设】S1（工业科技蓝）
【交互深度档位】L3
【数据规模】默认（每域 5~15 条 + 汇总 + 模板池；全平台约 60 个数据域、149 个 API 桩）
【贯穿性剧本】空压机管网压力异常 24h 处置倒计时，贯穿告警/隐患/传感/边缘节点/系统自监测五处；
  员工"钱进"低信用分，贯穿领料阻断/门禁拦截/工具柜拦截三处
【特殊机制】配电房智能门禁"本地断网仍可刷证、云端只读不可控"的云边安全边界，贯穿白名单/审计/双人授权
【交付批次】门户 + _shared 骨架先行，之后按 01→02→03→05→06→04→07→08→09→10→11 分批
```

## 填写示例（标准多页项目）

```
【运行模式】A
【项目名称】XX园区智慧安全管理平台
【行业与业务域】园区安全 · 消防安防通行综合管控
【模块清单】01 安全态势 ｜ 02 告警中心 ｜ 03 消防管控 ｜ 04 人员通行 ｜ 05 设备台账
【视觉风格预设】S1（工业科技蓝）
【交互深度档位】L3
【交付批次】门户 + _shared 骨架先行，之后每批 1-2 个模块
```

> 注：示例中的具体项目名、剧本、机制均为演示内容，与任何真实项目无关；执行时以用户实际槽位为准。
