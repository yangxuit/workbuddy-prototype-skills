# 站点编排规范（必读）

## 1. 站点结构

每条动线为一个对象：`{ id, name, steps: [{ page, title, say, tip, focus, view, filter, clip }] }`

| 字段 | 必填 | 说明 |
|---|---|---|
| page | 是 | 站点所在页面文件 |
| title | 是 | 站点标题（"第 N 站 · 页面名：看点名"式命名） |
| say | 是 | 讲解词，按【讲解词风格】与【演示时长】配置详略，不超过 3 句 |
| tip | 否 | 互动提示行。开启【互动提示】时按"**穷举识别 × 精选编入**"规则编排：通读原型穷举全部可交互操作点（表单/校验/流转审批/模态/提交确认/模拟触发/加载动画等），按演示价值精选分配到对应站点——① 完整业务闭环类互动优先整段编入（如"接单→检修→签名销号"走全流程）；② 同一站点多个互动合并列举；③ 总量超时则低价值互动降为"可选动作"标注，守住【演示时长】（时长守恒：每站讲解词约 50~75 秒量） |
| focus | 否 | 目标元素 CSS 选择器（聚焦高亮）。约束：①必须与页面真实元素核对（存在且可滚动入视野）；②目标由异步渲染/前置互动产生时（如"提交后才出现的签名按钮"），改选**稳定存在的容器**（如操作区容器）作锚点——演示者跳过互动直达本站时选择器不存在，6s 轮询空转后失焦 |
| view | 否 | 目标视图/Tab（可带查询参数） |
| filter | 否 | 筛选协议：进入列表页时自动设置筛选器（如按机组/类别过滤），确保目标记录出现在第一屏 |
| clip | 否 | 默认选中协议：进入媒体/详情列表页时自动选中并播放/展开指定条目 |

## 2. 首末站规则（强制）

- **首站 = 开场**：在【导航宿主页】，讲动线全貌（事件链/价值主张一览），给观众"接下来会看到什么"的预期；
- **末站 = 结束**：回到【导航宿主页】，收尾总结（全程链路一句话复述）+ Q&A/自由浏览建议。

## 3. 叙事链模式（按【叙事链模式】三选一）

| 模式 | 站数 | 结构 | 适用 |
|---|---|---|---|
| 深度贯穿链 | 8~12 | 开场 → 5~10 个跨模块站点（每站一个视角/页面，编号可互证）→ 结束 | 客户评审、深度售前 |
| 标准四段链 | 4 | 出处/背景 → 方案/机制 → 动作/实例 → 结果/闭环 | 单场景、单功能演示 |
| 速览链 | 2~3 | 开场（含 1~2 个核心看点）→ 结束 | 高层快闪、展会走场 |

## 4. 派生工厂（可选，多条同构动线时启用）

同构动线（如 N 个场景各一条四段链）**禁止逐条手写**：声明派生规则，由业务数据自动生成站点（字段从数据域取：出处字段→站1、方案字段→站2、关联实例→站3、关联结果→站4）；个别对象链路特殊时在工厂内写定制分支覆盖。收益：数据变更动线自动同步，永不穿帮。

## 5. 入口与界面设计

- 演示对象卡片上提供主入口按钮（文案按【入口文案】），旁边可保留次入口（自由浏览/详情）；
- 入口按钮点击即 `startTour`；详情弹层内同样提供入口（两处均可启动）；
- 引导条 z-index 高于页面所有元素；不遮挡聚焦目标（引导条贴底时聚焦元素滚动至视口中上部）。
