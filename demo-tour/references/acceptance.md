# 质量验收清单（交付前逐项自查）

## 动线完整

- [ ] 无头浏览器（或逐站人工）走完全部站点：首站→末站→结束，全程零 JS 错误
- [ ] 跨页跳转后引导条恢复、进度正确；上一步回退正确
- [ ] 每站 focus 聚焦命中（异步元素等待后命中；筛选/重渲染场景二次聚焦生效；验收断言须轮询等待至上限再裁定，勿在切站后立即断言）
- [ ] filter/clip 协议生效：目标记录在第一屏可见/自动选中
- [ ] 深浅主题页引导条均可读；结束清理干净（无残留高亮/引导条）

## 数据可信

- [ ] 讲解词引用的编号逐一对得上页面数据
- [ ] 入口可用性由交付状态自动判定
- [ ] 派生动线与手写分支数据一致

## 演示体验

- [ ] 讲解词照念通顺、详略符合【演示时长】与受众
- [ ] 互动提示行操作路径真实可完成
- [ ] 原有自由浏览行为不受影响（无演示时页面默认态不变）
