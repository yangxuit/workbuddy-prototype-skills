# 引擎能力规范与数据同源铁律（必读）

## 1. 六项必备能力

1. **跨页面自动跳转**：站点可分布在不同页面文件，点"下一步"自动跳转目标页（URL hash 携带 `#/tour@动线ID` 恢复标记），新页面加载后自动恢复演示到当前站；
2. **进度持久化**：按【进度持久化】配置记录当前站索引，跨页跳转/刷新不丢；**实现约束：切换站点时必须"先写进度、后发起跳转"**（若先跳转后写，目标页恢复时读到旧索引会回跳上一站，形成演示死循环）——进度写入只允许发生在 `go/prev/next` 决策点，`renderTour` 内不再重复写；
3. **视图自动切换**：站点可指定目标页内的视图/二级 Tab（hash 形态 `#/视图名@动线ID`，视图名可带查询参数如 `flow?wo=编号`），进入即到位；
4. **目标元素聚焦**：每站可配置 CSS 选择器，目标元素加【聚焦高亮样式】并平滑滚动入视野；元素为异步渲染时需轮询等待，**轮询上限必须按时间（毫秒）计而非帧数计**——帧计数在高刷屏/高 fps 环境实际等待时长会缩水（240帧@86fps≈2.8s），推荐上限 6s；列表被筛选/重渲染重建 DOM 时需二次确认重聚焦；
5. **深浅主题双适配**：引导条与高亮在【主题适配】声明的各主题形态下均清晰可读；引擎内置 `body.dark` 与 `body.screen-on`（hifi-prototype 深色大屏形态）两套深色适配，自定义主题在此追加选择器；
6. **结束清理**：结束时 Toast 提示 + 引导条移除 + 高亮清除，页面回到自由浏览状态；演示中途可随时"上一步"回退或"✕"中止。

## 2. 引导条信息结构（每站显示）

```
┌────────────────────────────────────────────┐
│ ▶ 引导演示  动线名          第 N/M 站    ✕ │
│ 本站标题                                    │
│ ┃ 讲解词（可照念的 1~3 句台词）              │
│ ┃ ✋ 互动提示（可选的手动操作指引）           │
│                    [上一步]  [下一步 →/结束] │
└────────────────────────────────────────────┘
```

## 3. 引擎 API 契约（实现时暴露，供页面与测试调用）

- `startTour(id)`：从第 1 站启动；
- `endTour()`：结束并清理；
- `resumeTour()`：页面加载后按 hash 恢复（各页面初始化尾部统一挂载恢复钩子）；
- `tourStep()`：返回当前站信息 `{ id, step, page, ...站点数据 }`，供页面适配默认态（如联动选中指定记录）；
- `onTourStep(cb)`（页面侧挂载 `CMP.onTourStep = function(st){...}`）：每次切站渲染后与结束时回调（结束时传 `null`），供页面做确定性联动（如收起抽屉、清筛选）。勿依赖 hashchange 做联动——`view:null` 的页内切站 hash 不变，事件不触发；
- 防御：恢复时当前页与目标站页面不一致 → 自动跳转目标页；目标视图不存在 → 激活默认视图。**识别失败 ≠ 白屏。**

## 4. 数据同源铁律（勿删）

1. 动线编排数据与业务 mock/真实数据**同层存放**（同一数据源文件），不另建平行数据源；
2. 讲解词中的**编号/数值/人名必须引用原型真实数据**，禁止编造；
3. 演示入口的可用性由依赖页面/模块的交付状态**自动判定**（就绪才亮按钮），禁止手工开关造成"点了进不去"；
4. 站点 focus 选择器必须与页面真实元素核对；页面 id/class 变更时动线同步维护。

## 5. 引擎资产使用方式

`assets/tour-engine.js` 为按本规范实现并经实测的引擎（IIFE 挂 `window.Tour`，含跨页恢复、6s 时间上限轮询聚焦、筛选/选中协议）。目标原型无同类引擎时：

1. 复制该文件到目标原型 `_shared/`（或等价共享目录），改名 `tour.js`；
2. 按【聚焦高亮样式】【引导条位置】【主题适配】配置调整 CSS 令牌（引擎内样式集中定义于头部，便于定制）；
3. 动线数据按数据同源铁律写入原型的 mock 数据层（`DB.tours` 形态见 assets/example-baoxiu/_shared/mock.js）；
4. 各页面初始化尾部挂载 `Tour.resume()` 恢复钩子；
5. 禁止从零重写引擎引入回归；引擎能力缺口（如自动播放）在参考实现之上增量扩展。

完整接入示例见 assets/example-baoxiu/（双击 index.html 可体验实际效果）。
