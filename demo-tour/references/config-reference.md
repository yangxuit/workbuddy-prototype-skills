# 配置项速查表与填写示例

demo-tour 技能的输入参数字典。第 2 步收集配置时以本表为准；未提供的配置项一律按默认执行，不追问用户。

## 配置项速查表

| 配置项 | 作用 | 填写示例 | 建议默认值 |
|---|---|---|---|
| 原型技术形态 | 决定跳转/恢复实现方式 | 纯静态 HTML + hash 路由 | 同左（SPA 路由亦可，恢复标记改路由参数） |
| 导航宿主页 | 首末站所在页 | index.html | 门户/索引页 |
| 演示对象 | 动线清单与站点；跨产品复用可填"AI 推导"走推导-确认模式 | T1 空压机高温应急处置（10 站，见站点表） | 至少 1 条；不确定对象时用 AI 推导 |
| 叙事链模式 | 站数与结构档位 | 深度贯穿链 | 客户演示取深度链；速览用 2~3 站 |
| 目标受众 | 讲解词视角与术语密度 | 客户高层决策者 | — |
| 演示时长 | 单链目标时长，决定讲解词详略 | 8~10 分钟 | 8~10 分钟（时长守恒：每站约 50~75s） |
| 讲解词风格 | 话术基调 | 口语卖点型 | 对外售前取口语卖点型 |
| 互动提示 | 手动操作指引开关，开启后按穷举×精选规则编入 | 开启：闭环类优先整段编入 | 开启（增强临场感） |
| 聚焦高亮样式 | 高亮视觉 | 橙色脉冲描边 | 同左（警示系统可换品牌色） |
| 引导条位置 | 悬浮条位置 | 底部居中 | 底部居中（顶部易与页面顶栏冲突） |
| 主题适配 | 双主题适配声明 | body.screen-on | AI 自动探测；探测失败或需指定时手填 |
| 进度持久化 | 跳页/刷新保持进度 | sessionStorage | sessionStorage |
| 入口文案 | 按钮文字 | ▶ 引导式演示（N步·自动翻页） | 同左 |
| 派生工厂 | 同构动线自动生成 | 场景四段式→4 站链 | ≥3 条同构动线时启用 |
| 验收方式 | 交付前验证手段 | 无头浏览器走查 | 无头浏览器 + 人工各一遍 |

## 三种典型场景填写示例

**示例1 · 客户深度评审（长链）**

```
【演示对象】T1 空压机高温应急处置（深度贯穿链 12 站：大屏首发现→监控细节→告警→诊断→
  寿命预测→视频取证→数据回放→工单闭环→合规归档）
【目标受众】客户高层 + 技术评审
【演示时长】10~12 分钟
【讲解词风格】口语卖点型（数值卖点前置，"93%置信度""提前23天备件提示"）
【互动提示】开启（末段工单站当众走完审批+签名）
```

**示例2 · 场景速览（四段链）**

```
【演示对象】SC-05 越限操作预警（标准四段链：危险点出处→识别方案→告警实例→处置闭环）
【目标受众】现场操作与安全管理人员
【演示时长】3~4 分钟
【讲解词风格】教学引导型（每站一个"你再看这里"的引导句）
【派生工厂】启用：8 个场景由四段式数据派生，1 个无告警场景写定制分支
```

**示例3 · 展会快闪（速览链）**

```
【演示对象】平台总览速览（3 站：全景价值→1 个王牌案例→结束引流）
【目标受众】展会人流（驻留 1~2 分钟）
【演示时长】90 秒
【讲解词风格】口语卖点型（每站 1 句话，超短）
【互动提示】关闭（节奏优先）
```

> 注：示例中的数值卖点（"93%置信度"等）为演示写法，实际执行时必须替换为目标原型 DB 中的真实数据（数据同源铁律）。
